WHAT THIS SAYS FOR THE WRITE-UP
  Adding an object type to fit one paper does not create a strict match; it creates a correctly isolated paper. Strict similarity needs two papers
  that act on the same object with the same verb. The ontology addition pays off only when the corpus gets a second trajectory-mechanism paper
  (e.g. Decision Diffuser, Trajectory Transformer, MPC-with-CEM), at which point Diffuser x that paper is the test. Relaxed is the layer that
  connects a new field to the corpus on day one (DDIM 0.50 via represented_state); strict is the layer that says "nothing here does what this does".
